# 🌐 My Web Development Journey

Welcome to my personal learning repository! This repo serves as a progress log, journal, and showcase of my journey into front-end web development—starting from scratch with **HTML5**, **CSS3**, and **Vanilla JavaScript**.

---

## 📌 About This Repository

I started learning web development to understand how modern websites work under the hood and to build interactive, responsive web applications from the ground up. Here, I document everything I learn—from basic layouting concepts to Single Page Application (SPA) architectures and deployment workflows.

---

## 🛠️ Tech Stack & Learning Focus

- **HTML5**: Semantic markup, accessibility (`aria-*`), native components (`<dialog>`, `<video>`, `<audio>`), metadata & favicons.
- **CSS3**: Responsive Design, Flexbox, CSS Grid, Custom Properties (CSS Variables), Glassmorphism & Modern UI styling.
- **Vanilla JavaScript (ES6+)**: DOM Manipulation, Event Listeners, Fetch API, Modular JS architecture, and SPA Routing without heavy frameworks.
- **Tools & Deployment**: Git, GitHub, VS Code, FFmpeg (media processing), and Vercel.

---

## 🚀 Featured Showcase Project

### 🎬 Zenless Zone Zero - Fan-Made Landing Page
A responsive, modular Single Page Application (SPA) fan page built using pure HTML, CSS, and Vanilla JavaScript.
- **Key Features**: Dynamic SPA content fetching, background video optimization for mobile & desktop, trailer modal dialog, custom audio controls, and toast notifications.
- **Live Demo**: https://jane-doe-zzz-web.vercel.app
- **Source Code**: https://github.com/OakJustify/Jane-Doe-ZZZ_Web.git
- **Key Takeaways**: Learned SPA mechanics (`fetch()`), CSS variable management, modular file separation (`html/`, `css/`, `js/`), and media resource optimization.

## 📚 Key Concepts Mastered

- [x] **Semantic HTML & Metadata**: Viewport configurations, UTF-8 charsets, theme-colors, and favicons.
- [x] **Modular Architecture**: Separating CSS and JS per page/component for maintainable code.
- [x] **Responsive & Adaptive Media**: Using `@media` queries and `window.matchMedia` for seamless mobile vs. desktop viewports.
- [x] **Vanilla JS Routing**: Swapping view DOM containers dynamically without full page refreshes.
- [x] **Git & Deployment Workflows**: Repository management, Git CLI operations, and Vercel continuous deployment.
